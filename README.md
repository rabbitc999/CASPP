# caspp —— C++17 代数符号计算器

一个从零实现的计算机代数系统（CAS）核心。符号表达式树、大整数运算、多项式算法、
微积分、方程求解与 Groebner 基，全部基于自研内存池分配。

参考了 `gitee.com/rabbitc999/cas` 的内存分配器设计与 sympy 的算法组织方式，
命名风格沿用 Qt 式驼峰（`Cas::Engine`、`calculate()`、`memoryStats()`）。

以 [MIT 协议](LICENSE) 发布，可自由使用、修改、分发，保留版权声明即可。

## 构建与运行

```bash
mingw32-make            # 构建 build/caspp 与全部测试
mingw32-make test       # 运行全部测试（等价于 make check）
mingw32-make run        # 启动 REPL
mingw32-make bench      # 跑一组较重的表达式
mingw32-make clean      # 清理 build/
```

需要 g++ 支持 C++17。产物全部落在 `build/`，源码树保持干净。

### 命令行

```bash
build/caspp -c "diff(x^2*sin(x), x)"      # 单条求值
build/caspp -q -c "factor(x^2-1)"         # 只输出结果，不打印提示
build/caspp                               # 进入 REPL
```

参数：`-c/--command`（可重复）、`-q/--quiet`、`-u/--unicode`、`-v/--version`、`-h/--help`。

### 线性代数

矩阵写作嵌套列表 `[[1,2],[3,4]]`（`[1,2,3]` 视为 1×3）。全部运算在符号域上进行，
元素可以是整数、有理数、根式或含参数的表达式，不经过浮点。

| 命令 | 说明 | 示例 |
| --- | --- | --- |
| `det` / `determinant` | 行列式（Bareiss 分数消元，全程精确整除） | `det([[a,b],[c,d]])` → `-b*c + a*d` |
| `inv` / `inverse` / `invert` | 逆矩阵（增广 `[A｜I]` + 行最简形） | `inv([[1,2],[3,4]])` → `[[-2, 1], [3/2, -1/2]]` |
| `transpose` / `trans` | 转置 | `transpose([[1,2,3],[4,5,6]])` → `[[1, 4], [2, 5], [3, 6]]` |
| `trace` / `tr` | 迹（仅方阵） | `trace([[1,2],[3,4]])` → `5` |
| `matmul` / `dot` | 矩阵乘法 | `matmul([[1,2],[3,4]],[[5,6],[7,8]])` → `[[19, 22], [43, 50]]` |
| `rank` | 秩 | `rank([[1,2,3],[4,5,6],[7,8,9]])` → `2` |
| `rref` | 行最简形 | `rref([[1,2,3],[4,5,6]])` → `[[1, 0, -1], [0, 1, 2]]` |
| `charpoly` | 特征多项式（Faddeev–LeVerrier 递推） | `charpoly([[1,2],[3,4]])` → `x^2 - 5*x - 2` |
| `eigenvals` / `eigenvalues` | 特征值（解特征多项式） | `eigenvals([[1,2],[3,4]])` → `{1/2*(sqrt(33) + 5), 1/2*(-sqrt(33) + 5)}` |
| `identity` / `eye` | n 阶单位阵 | `identity(3)` |

矩阵命令可以任意嵌套：中间结果会以结构化形式传给外层，可以是标量也可以是矩阵。

```
det(inv([[1,2],[3,4]]))                        → -1/2
trace(matmul(A, inv(A)))                       → 2          （A 为 2 阶方阵时恒成立）
transpose(inv([[1,2],[3,4]]))                  → [[-2, 3/2], [1, -1/2]]
```

实现上，`Result::text` 对矩阵结果会在开头附一个内部标记 `\x1F`。引擎重新解析表达式前
会先剥掉它（标记不是合法字符），并把「这段文本代表矩阵」的信息保留在单独的分支里，
因此嵌套调用既能拿到矩阵结构、最终输出又保持矩阵渲染。

奇异矩阵会明确报错，不会返回伪逆或零矩阵：

```
inv([[1,2],[2,4]])                             → 错误：矩阵不可逆（行列式为 0）
```


### 特殊函数

已知值是精确有理数或 `√π` 的整数倍，未知值保持符号形式（`gamma(1/3)` 原样返回），
不会退化成浮点数。极点（`gamma(0)`、`gamma(-1)`）同样保持未求值。

| 命令 | 说明 | 示例 |
| --- | --- | --- |
| `gamma(z)` | Γ 函数 | `gamma(5)` → `24`，`gamma(-3/2)` → `4/3*sqrt(pi)` |
| `factorial(n)`、`n!` | 阶乘 | `20!` → `2432902008176640000` |
| `factorial2(n)`、`n!!` | 双阶乘 | `7!!` → `105`，`(-1)!!` → `1` |
| `beta(a, b)` | B 函数 = Γ(a)Γ(b)/Γ(a+b) | `beta(2,3)` → `1/12` |
| `binomial(n, k)` | 组合数（`k > n` 时为 0） | `binomial(20,10)` → `184756` |
| `harmonic(n [, r])` | 谐波数 / 广义谐波数 | `harmonic(5)` → `137/60` |
| `erf` / `erfc` / `erfi` | 误差函数族 | `erfc(0)` → `1` |
| `Ei` / `li` | 指数积分、对数积分 | 已知点折叠，其余保持符号 |
| `besselj` / `bessely` / `besseli` / `besselk` | Bessel 函数 | `besselj(0,0)` → `1` |
| `bernoulli(n)` | 伯努利数（递推 + 缓存） | `bernoulli(12)` → `-691/2730` |
| `specialsimplify` / `spsimp` | 折叠表达式中的特殊函数 | `spsimp(gamma(5)+binomial(4,2))` → `30` |

Γ 的半整数两支按下列恒等式处理，避免逐项递推到分数界：

```
Γ(1/2 + n) = (2n)! / (4^n · n!) · √π      gamma(7/2)  → 15/8*sqrt(pi)
Γ(1/2 - n) = (-4)^n · n! / (2n)! · √π     gamma(-5/2) → -8/15*sqrt(pi)
```

### 级数求和与敛散性

区间写作 `i=1..n`，上限写 `oo` 表示无穷。求值顺序为：变量无关 → 小整数直接展开 →
多项式通项 → 线性拆分 → 幂项 → 几何 → 算术-几何 → 裂项。顺序本身有讲究：多项式分支
必须早于加法拆分，否则 `3i^2-2i+1` 会被拆成三项各自求和，失去合并成标准多项式的机会。

| 类别 | 公式 | 示例 |
| --- | --- | --- |
| 幂和 | Faulhaber，用伯努利数展开 | `sum(i^3, i=1..n)` → `1/4*n^4 + 1/2*n^3 + 1/4*n^2` |
| p 级数（有限） | `H(b,r) - H(a-1,r)` | `sum(1/i^2, i=1..10)` → `1968329/1270080` |
| p 级数（无穷） | `ζ(2n) = (-1)^(n+1) B_2n (2π)^(2n) / (2(2n)!)` | `sum(1/i^4, i=1..oo)` → `1/90*pi^4` |
| 几何级数 | `q^a (1-q^(n+1))/(1-q)` | `sum((1/2)^i, i=0..oo)` → `2` |
| 算术-几何 | `Σ i q^i = q/(1-q)^2` | `sum(i*(1/2)^i, i=0..oo)` → `2` |
| 裂项 | `1/((i+a)(i+b)) = 1/(b-a)(1/(i+a) - 1/(i+b))` | `sum(1/(i*(i+1)), i=1..oo)` → `1` |

裂项对无穷上限单独处理：两个调和尾项各自发散，但相减后只剩前 `gap = b-a` 项，
引擎直接展开成 `Σ_{k=0}^{gap-1} 1/(a+a₀+k)` 求值，而不是分别算两个发散的和。

`converge` 先尝试闭式求和——能得出有限值即收敛（并给出和），得出 `Infinity` 即发散，
闭式失败时再退回比值判别：

```
converge(1/i^2, i=1..oo)                       → 收敛，和为 1/6*pi^2
converge(1/i, i=1..oo)                         → 发散
converge(2^i, i=0..oo)                         → 发散
```

`guess` 由前几项猜通项，依次尝试等比 → 等差 → Newton 前向插值（≤4 阶）：

```
guess([1,3,5,7,9])                             → 2*n + 1
guess([1,4,9,16,25])                           → n^2 + 2*n + 1
guess([2,4,8,16,32])                           → 2*2^n
```


### 常微分方程

未知函数默认 `y`，自变量默认 `x`；撇号写法 `y'` / `y''` 会在解析阶段直接生成
`Derivative(y, x, n)`（阶数**总是显式写出**，与 `diff` 产生的节点形态一致，
否则 `equals` 比较会因为参数个数不同而失败）。

```
dsolve(eq)                    求解，eq 形如 y' = y、y'' + y = 0
dsolve(eq, y)                 指定未知函数
dsolve(eq, y, t)              指定自变量
dsolve(eq, y(0)=1, ...)       带初值条件，定出积分常数
```

**一阶**按「线性 → 伯努利 → 齐次 → 可分离」的顺序识别，这个顺序是刻意的：
一阶线性最通用且解式最干净；伯努利要求右端恰好是「y 的一次项 + y^n 项」，
与线性互斥；齐次与可分离放最后避免抢走前两者。

| 类型 | 判据 | 示例 |
| --- | --- | --- |
| 一阶线性 | `y' = P(x)y + Q(x)`，积分因子 `e^{∫P}` | `dsolve(y' + 2*x*y = x)` → `y = e^(-x^2)*(C1 + 1/2*e^(x^2))` |
| 伯努利 | `y' = P(x)y + Q(x)y^n`，换元 `v = y^(1-n)` | `dsolve(y' + y/x = y^2)` → `1/(x*(C1 - log(x))) - y = 0` |
| 齐次型 | 右端 0 次齐次，换元 `u = y/x` | `dsolve(y' = (x^2+y^2)/(x*y))` → `y^2/(2*x^2) + C1 - log(x) = 0` |
| 可分离 | `y' = f(x)g(y)` | `dsolve(y' = x*y^2)` → `-1/2*x^2 - C1 - 1/y = 0` |

齐次性判定用**数值比例检验**：比较 `F(2,3)` 与 `F(4,6)` 是否相等，避开「符号替换后
还要约公共因子」的困难。`F(u)` 由 `x=1, y=u` 代入取得，解出后把 `u` 回代成 `y/x`。

**二阶常系数线性** `a·y'' + b·y' + c·y = f(x)`，缺项（无 `y'`、无常数项、`y''=0`）
也能抽出系数。齐次部分按特征方程判别式分三种情形：

| 判别式 | 齐次解 | 示例 |
| --- | --- | --- |
| Δ > 0（两相异实根 r₁, r₂） | `C1 e^{r₁x} + C2 e^{r₂x}` | `dsolve(y'' - 3*y' + 2*y = 0)` → `y = C1*e^(2*x) + C2*e^x` |
| Δ = 0（重根 r） | `(C1 + C2 x) e^{rx}` | `dsolve(y'' + 2*y' + y = 0)` → `y = e^(-x)*(C2*x + C1)` |
| Δ < 0（共轭复根 α ± βi） | `e^{αx}(C1 cos βx + C2 sin βx)` | `dsolve(y'' + y = 0)` → `y = C1*cos(x) + C2*sin(x)` |

非齐次部分的特解用**待定系数法**：按 `f(x)` 的形状搭试探式（多项式 → 各次幂；
`e^{kx}`；`cos(kx)`/`sin(kx)`），代入后把结果展成若干加法项，逐个基函数令其系数为 0，
得到关于待定常数的线性方程组，再交给符号矩阵求解器消元。

基函数表不是写死的：除了试探式自身的项，还会自动纳入「代入式中不含待定常数的项」——
这些项代表试探式覆盖不到的基函数，必须令其系数为 0 才不会漏方程。

右端恰为齐次解时（共振）试探式要乘 `x`，引擎用「代入后是否恒为 0」来判定，
重根时再乘一次：

```
dsolve(y'' + y = sin(x))                       → y = -1/2*x*cos(x) + C1*cos(x) + C2*sin(x)
dsolve(y'' - 3*y' + 2*y = e^x)                 → y = -x*e^x + C1*e^(2*x) + C2*e^x
dsolve(y'' + 4*y = sin(2*x))                   → y = -1/4*x*cos(2*x) + C1*cos(2*x) + C2*sin(2*x)
```

线性方程与二阶常系数给出**显式解** `y = …`；可分离、齐次型、伯努利只给**隐式解**
`F(x,y) = 0`（这类方程一般无法解出初等显式形式）。两种形式都带积分常数 `C1`/`C2`。

> 实现约定：方程先整理成残差 `a·y'' + b·y' + c·y + rest = 0`，因此右端
> `f(x) = -rest`——这一处符号必须翻转，否则特解会整体取反。

### 初值问题

把初始条件作为**额外参数**跟在方程后面，引擎会先求通解、再逐条代入定出常数：

```
dsolve(y' = y, y(0) = 1)                       → y = e^x
dsolve(y' + y = x, y(0) = 1)                   → y = e^(-x)*(x*e^x - e^x + 2)
dsolve(y' = x*y, y(0) = 2)                     → y = 2*e^(1/2*x^2)
dsolve(y'' + y = 0, y(0) = 0, y'(0) = 1)       → y = sin(x)
dsolve(y'' + y = 0, y(0) = 1, y'(0) = 0)       → y = cos(x)
dsolve(y'' - 3*y' + 2*y = 0, y(0) = 1, y'(0) = 2) → y = e^(2*x)
```

条件写法为 `y(点) = 值` 与 `y'(点) = 值`（也可写 `y''(点) = 值`）。要点：

- 条件数**少于**阶数时只解出部分常数，答案里保留剩余的自由常数
  （`dsolve(y'' + y = 0, y(0) = 0)` → `y = C2*sin(x)`）。
- 条件数**多于**阶数、或代入后矛盾时报错「初值条件无法确定积分常数」。
- 隐式解（可分离/齐次/伯努利）不做初值代入，传了条件会明确报错。
- 解析器对 `dsolve(`/`ode(` 自动开启**宽松模式**：`y(0)` 不再被读成 `y·0`，
  而是解析成对未知函数的调用。


### 积分能力

- 基本初等函数（幂、指数、对数、三角、双曲、反三角）
- 线性换元（自动识别内层导数为常数）
- 一般换元：被积函数形如 `F(g(x))·g'(x)` 时自动换元（`e^{x²}`、`(x²+1)^n`、`sin³x·cos x` 等）
- 分部积分（LIATE 式的 `uRank` 优先级，递归深度上限 6）
- 有理函数：分母一次 → 多项式除法 + 对数；分母二次 → 按判别式分三种情形，得到对数组合或 `atan`
- 有理函数加深：部分分式分解（一次因子可带重数，二次因子给 `A*x+B`），先 `toQuotient` 化成规范单分式再按分母次数分派
- 三角有理式：万能代换 `t = tan(u/2)`，代换后递归通分成单分式再积分
- 根式：`√(a²−x²) → x = a·sin t`、`√(a²+x²) → x = a·tan t`，按 `x^(±1/2)` 节点识别
- 幂与递推：`sin^n`/`cos^n`（奇次拆因子换元、偶次降幂）、`log^n`（分部递推）、`log(a·x+b)`
- 数值上更复杂的被积函数会被明确判定为「超出当前支持的积分规则集」，不会返回错误答案

```
integrate(x*e^(x^2), x)                        → 1/2*e^(x^2)
integrate(cos(x)*sin(x)^3, x)                  → 1/4*sin(x)^4
integrate(x/(x^2+1), x)                        → 1/2*log(x^2+1)
```

### 极限策略

依次尝试：直接代入 → 有理式约分（多项式 GCD）→ 洛必达 → 分子分母各自 Taylor 展开到 8 阶取首个非零项之商。
`±∞` 方向单独处理分子分母次数比较；仍无法判定时用 `x = 1/t` 换元转成 `t → 0`。
幂指型 `F^G`（`x^x`、`(1+x)^(1/x)`）统一改写为 `e^(G·ln F)`，先求指数上的极限再取指数。

### 因式分解策略

`factor` 按「多元 / 一元」两条路径分派。多元情形先 `expand`，再对每个自由符号
轮流把它当主元、其余符号当系数走一元流程，最后取「因子数最多且不含负指数」的候选
再组装；一元情形顺序固定：

1. 数值公因子
2. 一次因子（有理根定理 + 综合除法）
3. 剩余二次式 → 判别式拆分（判别式 `Δ = b²−4ac`；数值 `Δ` 走 `isqrt`，
   符号 `Δ`（如 `x²−y²` 的 `4y²`）逐因子开方；`Δ = 0` 时输出两个相同的因子）
4. 四次式拆两个首一二次因子 → 假设 `(x²+px+q)(x²−px+r)`，系数比较
5. 只含偶次项 → 令 `y = x²` 代换，在 `y` 上递归分解后换回，覆盖 `x⁴+2x²+1`
6. 剩余部分原样保留（不可约就不可约，不硬拆）

每次拆出的线性因子都做一次 **integralize**：逐项取有理系数分母的最小公倍数，
把分式因子化成「整系数分子 / 数值分母」，分母并入整体系数。`assembleFactors`
再摊平嵌套 `Mul`、按文本去重合并成幂、提取各因子的数值公因子（对展开项逐项求 gcd，
多变量因子同样适用），最后按文本排序保证输出稳定。

```
factor(x^4+x^2+1)                              → (x^2 + x + 1)*(x^2 - x + 1)
factor(x^8-1)                                  → (x - 1)*(x + 1)*(x^2 + 1)*(x^4 + 1)
factor(x^4+4)                                  → (x^2 - 2*x + 2)*(x^2 + 2*x + 2)
factor(x^2+2*x*y+y^2)                          → (x + y)^2
factor(4*x^2-9*y^2)                            → (-3*y + 2*x)*(2*x + 3*y)
factor(x^4+y^4)                                → x^4 + y^4          （有理域上不可约）
```

### 级数与驻点

- `taylor` 支持 Laurent 展开：奇点处先在 `(x−a)^k` 上展开，再逐项除以 `(x−a)^k`，因此 `taylor(exp(x)/x, 0, 3)` 会得到 `1/x + 1 + x/2 + x^2/6`
- `critical` 解 `f'(x) = 0` 得驻点，用 `f''` 符号区分极小（`>0`）、极大（`<0`）；`f''= 0` 时如实标注「无法判定」

### 内存模型

不使用全局 GC，改用**引用计数 + 不可变节点 + RAII `Ptr` 守卫**：

- 节点创建时 `m_refs = 1`，由返回它的 `Ptr` 持有
- `Ptr` 拷贝即 `retain`，析构即 `release`，计数归零时归还池
- `Ptr::borrow(NodePtr)` 用于临时观察，不改变计数
- 所有节点分配都走自研内存池（首次适配 + 块拆分 + 相邻空闲块双向合并），
  池未就绪时自动退回 `::operator new`

这样避免了参考项目里 mark-sweep GC 的悬垂风险，同时保留了池化带来的分配性能。

### 大整数

基 `2^32` 小端 limb，符号独立存储，`±2^61` 以内走内联表示。

- 乘法分段：≤32 limb 教科书算法 → ≤96 limb Karatsuba → 更大规模走三段分解 + NTT（模数 `2013265921`，原根 31，每 limb 拆 4 段 × 8 位）
- 除法用移位相减长除（参考 magel 的 `divmodBase`）
- 精确开方、k 次整数根（二分）、GCD

## 已知边界

- 部分分式覆盖到「分母可分解为一次因子（可带重数）与不可约二次因子」；二次因子带重数、
  或代换后得到 `t^4+6t^2+1` 这类有理域不可约四次式时返回「超出支持的规则集」
- 因式分解在有理域上进行：`x^4+1`、`x^2+y^2`、`x^4+y^4` 这类有理域不可约的式子
  原样返回（不引入代数扩域）；多元分解逐变量轮流做主元，`x^2*y^2-1` 这类需要把
  `x*y` 整体当作一个主元的情形不会拆成 `(x*y - 1)*(x*y + 1)`
- 求解只覆盖一次、二次方程与线性方程组，高次方程依赖有理根定理
- 三角化简是规则驱动的有限轮不动点迭代，不做任意恒等式的通搜
- 输出保持精确有理数，不自动数值化
- 线性代数：只处理显式给出的有限矩阵，没有矩阵符号（`MatrixSymbol`）与分块运算；
  特征值只给出特征多项式在有理解范围内的根，复数根不返回；没有 SVD/QR/最小二乘；
  矩阵不支持 `^` 幂运算
- 特殊函数只折叠「值是精确有理数或 √π 整数倍」的情形；`gamma(1/3)`、`besselj(0,1)` 这类
  会原样保持符号形式，不做数值近似
- 级数求和：p 级数的无穷和只处理偶数指数（借 ζ(2n) 的 π 闭式），奇数指数（如 ζ(3)）
  没有闭式可给；裂项只覆盖分母能分解为两个整数偏移线性因式的情形；
  算术-几何级数只处理一次多项式乘 q^i
- 化简层未做分母符号归并，`sum(x^i, i=0..n)` 的输出是等价的 `(-x^(n+1)+1)/(-x+1)`
  而不是 `(1-x^(n+1))/(1-x)`
- 常微分方程：只支持一阶（线性/伯努利/齐次/可分离）与**常系数**二阶线性；
  变系数二阶（如 Euler 方程、Bessel 方程）不处理；Riccati 方程（`y' = x² + y²` 这类）
  不在支持范围内，会如实报错而不是给出错误答案；初值问题只在**显式解**上生效，
  隐式解不做常数代入；非齐次特解的试探式只覆盖
  多项式、`e^{kx}`、`cos/sin(kx)`，右端为这些的乘积或和时提示「超出待定系数法范围」
  并退化为只给齐次解
